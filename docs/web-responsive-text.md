# Responsive browser UI

The browser UI now uses one bounded measured-text layout cache (384 entries), actual Canvas font metrics, centered labels, word wrapping, and controlled ellipsis for overlong imported names. Portrait layouts retain the existing 540-unit design width and extend the height cap to 1440; CSS fitting respects safe-area insets and the visual viewport. The gameplay HUD separates level, landlord count, men, score, objective and alerts. Tool controls, walking controls, and flight prompts occupy their own footer. Notifications display sequentially. Level library cards use more vertical space on tall phones, achievement and outfit screens paginate in both orientations, and settings wrap narrow labels. Cutscene captions use stable layout during typewriter reveal; portrait scenes retain the full 960×540 stage. Editor trays reserve enough space for labels and buttons. Existing physics, level unlocks, save formats, and native ports are unchanged.

Local Chromium audit passed 363 screen checks, 2,622 hit rectangles and 5,600 measured text layouts across 11 viewports (280×480 through 1280×720), including all four settings tabs. The audit checks geometry and text bounds, not physical-device readability, emulator performance, or every individual cinematic frame. UI layout and keyboard/touch behavior remain subject to CI and real-phone validation.
