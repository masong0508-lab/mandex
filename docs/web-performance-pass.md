# Browser performance pass

Rubble broadphase buckets record the highest body ID, so queries cannot repeatedly examine already-processed or self-only candidates. Static grid contacts use clipped row bounds, with the original virtual ground and contact order preserved. Wallpaper scan starts at the visible edge, backing up through a continuous run so the original pattern remains aligned. The raster cache compares exact paint keys and local coordinates, bypassing repeated hashing and bounds calculations for unchanged slabs. Important ring cues take precedence over decorative particles in a full FX pool; off-screen particles are culled using conservative paint bounds. Small in-game character meshes use 24x8 rather than 48x16 hair subdivisions on low-detail presets; high detail and offline sprite generation retain the original mesh. Fixed a previously occluded ordinary outfit crease in the seated rendering test.

Median CPU time per collision step measured approximately 0.323 ms before and 0.215 ms after in the repeat run; sampled physics state matched. This is a microbenchmark, not a real-phone FPS guarantee. Regression compares 80 seeded scenarios (640 substeps), including world edges and ground, against the original contact iteration; cache and FX tests run in the contract gate.
