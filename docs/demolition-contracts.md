# Demolition contracts — first expansion milestone

Browser-only, independently saved contract mode: Play > Contracts. Twelve authored districts with Open, Bank, Chain and Guard layouts. Shared campaign level IDs, creator saves, and native ROM campaign remain unchanged. Contracts use destructible rooms, TNT, rubber, materials and landlord AI. Guard behavior respects Fight Back.

Only the selected 120×60 map is constructed; the menu stores compact descriptors. The existing save key is retained; contract stars are separate from campaign/custom wins and reset with Reset Progress.

The web and shared native blast loops skip empty, wallpaper-free cells and clip to world bounds, retaining row-major damage order. Tests exercise all layouts and browser blast equivalence.

This is the first content milestone, not a 3 MB shipped asset expansion. Native contract menus, device/emulator performance, playthrough balancing and further authored content remain outstanding. No padding or duplicate assets are used to meet a byte target.
