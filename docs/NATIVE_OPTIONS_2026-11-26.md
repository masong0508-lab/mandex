# Console options parity

Title and pause: X opens four pages (Play, Performance, Audio, Data). DS/3DS also use touch tabs and rows. L/R pages on handheld; X/Y on Dreamcast. A/tap changes or explicitly confirms, B closes. No game input can leak through an open options menu. Erasing progress requires two explicit presses on the same action and is title-only; reset settings preserves progress. Save now writes via each existing storage backend. Profiles affect decorative draw density, DS idle overview refresh, and 3DS low-end stereo disable, not simulation timing or collision math. Full/Eco selection, shake reduction, aim guide, music and sound effects, monitor, start tool, AI, collapse. v3 stores preferences in one added byte plus one previously reserved bit, reads v1/v2 saves and keeps the 1536-byte journal block size. Hardware verification pending.
